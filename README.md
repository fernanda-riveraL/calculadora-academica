# Calculadora Académica & Gestor de Ramos ✨
![Vista previa de la Calculadora Académica](preview.png)

Una aplicación de escritorio moderna desarrollada en **Python** con **CustomTkinter** para gestionar calificaciones universitarias, calcular notas ponderadas y simular promedios de aprobación mediante persistencia en archivos **JSON**.

A modern desktop application built with **Python** and **CustomTkinter** to manage university grades, compute weighted averages, and forecast passing marks with local **JSON** persistence.

---

## 🌸 Características / Features
- **Gestión por Asignaturas / Course Management:** Registro dinámico de ramos con paleta de colores personalizada y edición de nombres.
- **Ponderaciones & Proyección 4.0 / Passing Forecast:** Cálculo automático de puntos aportados y proyección exacta de la nota requerida en el porcentaje restante para aprobar con 4.0.
- **Modalidad Examen Final (60% / 40%):** Simulación opcional de nota de presentación semestral frente a la exigencia del examen de fin de semestre.
- **Gráfico Circular / Progress Ring:** Visualización en dona del avance evaluado acumulado.
- **Accesibilidad & Bilingüe / Accessibility & i18n:** Escalado interactivo de tamaño de letra (`A-` / `A+`), guía contextual de ayuda (`🔍`) y selector instantáneo entre Español e Inglés.
- **Persistencia Local / Persistence:** Guarda automáticamente el perfil del estudiante, semestre activo y evaluaciones en `notas.json`.

---

## 🛠️ Tecnologías / Tech Stack
- **Python 3.15**
- **CustomTkinter**

## 🚀 Instalación y Uso / Installation & Usage

1. Clona el repositorio:
```bash
git clone [https://github.com/fernanda-riveraL/calculadora-academica.git](https://github.com/fernanda-riveraL/calculadora-academica.git)
cd calculadora-academica
```

2. Instala CustomTkinter:
```bash
pip install customtkinter
```

3. Ejecuta la aplicación:
```bash
python app.py
```
